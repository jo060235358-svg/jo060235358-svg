# ソーレン・リンドクヴィスト (Soren Lindqvist)

`システムプログラマ` • `ストレージエンジン` • `リアルタイムオーディオDSP` • `スウェーデン・ストックホルム`

こんにちは。超低レイテンシの分散ストレージシステムや、リアルタイム音響演算エンジンの設計・実装を行っています。日頃はRustとモダンC++によるシステムプログラミング、io_uringを活用したゼロコピーなLinuxカーネルI/O、決定論的有限オートマトン（FSM）の構築に取り組んでいます。

キャッシュミスをプロファイリングしたり先行書き込みログ（WAL）を設計していないときは、モジュラーシンセサイザーのパッチングを探求したり、エチオピア産コーヒー豆をV60でドリップしたり、北欧のグラベルロードをバイクでツーリングしています。

---

## 🛠️ 主な研究・開発領域

- **超高スループット・ストレージエンジン**: LSMツリー型キーバリューストア、WAL、ロックフリーメモリアロケータの設計。
- **カーネルI/O・低レイテンシネットワーク**: `io_uring`の非同期パイプライン、カーネルバイパスパケット処理、eBPFによるマイクロ秒単位のレイテンシ可視化。
- **デジタル信号処理 (DSP)**: 音響波動シミュレーションおよび空間オーディオ合成のためのSIMDベクトル化アルゴリズム実装。
- **分散システム耐障害性**: Raft合意アルゴリズムの検証、および決定論的並行性テスト。

## 📂 代表的なオープンソースプロジェクト

### 1. `aether-db`
> Rustで実装された組み込み型永続LSMツリーストレージエンジン。非同期`io_uring`によるディスクI/Oを直結。
- **注力分野**: ゼロコピー・デシリアライゼーション、スキップリスト基盤のロックフリーMemTable、追記専用コミットログ。
- **技術スタック**: Rust, io_uring, Linux AIO, SIMDビットパッキング
- **設計規律**: クリティカルな書き込みパスにおける動的ヒープメモリ確保ゼロを維持。

### 2. `pulse-dsp`
> 空間オーディオ合成および室内インパルス応答シミュレーションのためのリアルタイム物理モデリング音響エンジン。
- **注力分野**: 96kHz / 24-bit環境において、バッファ遅延1.8ms未満でのマルチチャンネル波動方程式演算。
- **技術スタック**: C++20, AVX-512 / NEON組み込み関数, CMake, PortAudio

### 3. `trace-tap`
> Linuxソケットバッファの肥大化とカーネルTCPキューのターンアラウンド時間を追跡する軽量eBPFプローブ。
- **注力分野**: 超低オーバーヘッド（CPUペナルティ0.4%未満）での高頻度取引・配信ノード可観測性の実現。
- **技術スタック**: C, eBPF / libbpf, Zig, Linux Tracepoints

### 4. `nord-vibe`
> Neovim、Tmux、Alacritty間でカラーパレットやフォント合字、レイアウトをリアルタイム同期するCLIワークスペースマネージャ。
- **技術スタック**: Go, Unix Domain Sockets, TOML

## 📈 エンジニアリング哲学

1. **賢明さより正確性を優先する**: どんなに高速でも破損データを返すコードは無価値です。プロパティベーステストとファジングで不変条件を厳格に検証します。
2. **機械への共感（Mechanical Sympathy）**: CPUキャッシュ、分岐予測器、ページテーブル、メモリバス帯域幅を意識します。ハードウェアは抽象概念ではありません。
3. **決定論的テスト**: シード値で再現可能なステートマシンシミュレーションは、数週間にわたる本番試験よりも迅速に並行処理の競合を暴き出します。
4. **依存関係の最小化**: サードパーティのライブラリを追加するごとに将来の保守負債が増加します。十分に検証された標準インターフェースを信頼します。
